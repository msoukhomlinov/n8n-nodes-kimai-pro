# Workflow Learnings from n8n-nodes-kimai-pro Development

## Session Overview
- **Sub-agents spawned**: 14
- **Successful**: 11 (79%)
- **Failed**: 3 (21%) - directory rename broke session tracking
- **Total commits**: 62
- **Commit breakdown**: 22 fixes, 11 refactors, 2 QA, 2 chore

## Effectiveness Lessons

### What Worked Well
1. **Parallel sub-agents for independent tasks**: API audit + best practices review ran simultaneously
2. **Codex review cycle**: feedback → fix → review loop caught real issues
3. **Modular refactoring**: Splitting 4113-line file into 12 descriptors improved maintainability
4. **Incremental commits**: Small, focused commits made it easy to track changes

### What Didn't Work
1. **Directory rename**: Renaming project directory broke sub-agent session tracking
2. **Sub-agent errors**: 3 sub-agents failed due to directory rename, requiring restart
3. **Repeated codex feedback**: Same issues found multiple times (budget fields, language defaults)
4. **Large file edits**: Editing 4113-line file directly was error-prone

## Efficiency Lessons

### Time-Consuming Tasks
1. **Codex review cycles**: 3-5 minute wait per review, multiple rounds needed
2. **Sub-agent restarts**: Failed agents required manual intervention
3. **File reading**: Large files required multiple reads to understand structure

### Optimizations
1. **Batch fixes**: Group related fixes into single commits
2. **Pre-build validation**: Run build/lint before committing to catch errors early
3. **Targeted sub-agents**: Smaller, focused tasks complete faster

## Repeatable Patterns

### QA Workflow
```
1. API audit sub-agent → findings.md
2. Best practices sub-agent → findings.md
3. Implementer sub-agent → apply fixes
4. Reviewer sub-agent → verify changes
5. Codex review → catch remaining issues
```

### Fix Workflow
```
1. Read codex feedback
2. Identify affected files
3. Apply targeted fixes
4. Build + lint
5. Commit + push
6. Trigger codex review
```

### Cleanup Workflow
```
1. Identify stale files (grep/find)
2. Delete files
3. Verify no references broken
4. Commit cleanup
```

## Recommendations

1. **Use relative paths**: Store session data with relative paths to survive directory renames
2. **Batch codex feedback**: Address all P1 issues in one commit before triggering review
3. **Pre-validate changes**: Run build/lint before committing to catch errors early
4. **Smaller sub-agents**: Break large tasks into smaller, focused sub-agents
5. **Standardize fix workflow**: Create a template for addressing codex feedback
6. **Track file changes**: Maintain a list of modified files for easier verification
7. **Limit codex rounds**: Set a max of 3 review rounds before manual intervention
8. **Parallelize independent work**: Run API audit, best practices, and cleanup in parallel

## Session Tracking Issue

### Problem
When the project directory was renamed from `n8n-nodes-kimai` to `n8n-nodes-kimai-pro`, all sub-agent sessions broke because they stored absolute paths to the working directory.

### Symptoms
- Sub-agents reported: "Stored session working directory does not exist"
- Session files existed but pointed to old directory
- 3 sub-agents failed due to this issue

### Fix Applied
Updated all session JSONL files to use new directory path:
```bash
find session-artifacts -name "*.jsonl" -exec sed -i '' 's/n8n-nodes-kimai/n8n-nodes-kimai-pro/g' {} +
```

### Proposed Harness Fix
```json
{
  "session": {
    "use_relative_paths": true,
    "detect_directory_rename": true,
    "auto_update_paths": true,
    "fallback_to_cwd": true
  }
}
```
